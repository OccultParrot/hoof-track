# Hoof Track

A streamlined scheduling tool for farriers to track horse shoeing appointments.

## About

Hoof Track helps farriers maintain organized records of horses in their care, including shoeing dates, rotation schedules, and overdue notifications. Built with a clean console interface, it offers an efficient way to manage your farrier business.

## Features

- Add, edit, and remove horses from your rotation schedule
- Set custom rotation intervals for each horse
- Track last shoeing dates and identify overdue appointments
- Reset dates for multiple horses at once
- Access detailed horse information through the Master List
- Data automatically saves between sessions

## Quick Start

1. Download the latest release
2. Run the application
3. Use function keys to navigate (F1-F5)

## Controls

- **F1**: Add horse
- **F2**: Remove horse
- **F3**: Edit horse details
- **F4**: View master list
- **F5**: Bulk reset shoeing dates
- **ESC**: Exit

## Technical Details

- Built in C# with Spectre.Console for enhanced UI
- Uses JSON for data storage
- Includes logging for troubleshooting
